# Supplier Selection DSS (BIT2014 Final Project)

Model-driven Decision Support System for ranking suppliers.

- **Weights:** direct sliders or AHP pairwise comparison (with consistency ratio)
- **Ranking:** TOPSIS, cross-checked against a weighted-sum model
- **Transparency:** per-criterion contribution bars and a plain-language explanation
- **Sensitivity:** Monte Carlo perturbation of weights (1,000 runs), top-1 stability verdict
- **Data:** 12 synthetic suppliers (no real personal data)

## Run
Open `index.html` in any browser. No installation needed.
